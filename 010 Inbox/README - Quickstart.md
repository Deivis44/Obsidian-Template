# 010 Inbox - Quickstart

Usa esta carpeta para capturar sin friccion:

- Ideas.
- Links.
- Apuntes de clase.
- Tareas sueltas.
- Preguntas.
- Fragmentos que todavia no entiendes.

## Regla

Nada vive aqui para siempre. Procesa el Inbox a diario si puedes, o minimo en la revision semanal.

## Como procesar

Para cada nota pregunta:

1. Es accionable?
2. Es una responsabilidad continua?
3. Es conocimiento reutilizable?
4. Es material de estudio?
5. Ya no sirve?

## Destinos

- Tarea con resultado: `030 Projects`.
- Responsabilidad continua: `020 Areas`.
- Concepto/fuente/problema: `040 Knowledge`.
- Plan o revision: `050 Review`.
- Cerrado o viejo: `090 Archive`.
