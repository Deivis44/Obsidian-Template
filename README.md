# 📚 Obsidian Universal Template

![Showcase](SHOWCASE1.png)

> **Una plantilla completa y profesional para Obsidian que implementa las mejores prácticas de gestión del conocimiento y productividad personal.**

## 🌟 Características Principales

- **🗂️ Sistema de organización numérico** para mantener el orden perfecto
- **🎨 Iconos visuales** con stickers de Lucide para identificación rápida  
- **📝 Metodología híbrida** que combina Zettelkasten, PARA Method y GTD
- **🔌 Plugins esenciales** preconfigurados para máxima productividad
- **🎯 Estructura escalable** que crece contigo

## 📁 Estructura del Vault

```text
📦 Obsidian-Template/
├── 📦 000 Core/              # Sistema fundamental
│   ├── 🖼️ Resources/         # Materiales de referencia
│   └── 📄 Templates/         # Plantillas reutilizables
├── 📝 001 Notes/             # Sistema de notas
│   ├── 📥 00 Inbox/          # Bandeja de entrada
│   ├── 📤 01 Permanent/      # Notas permanentes procesadas
│   ├── 📋 02 References/     # Referencias y citas
│   └── 🗃️ 03 Archive/        # Archivo de notas antiguas
└── 📦 003 Projects/          # Gestión de proyectos activos
```

## 🚀 Inicio Rápido

### 1. Instalación

```bash
# Clona el repositorio
git clone https://github.com/Deivis44/Obsidian-Template.git

# Renombra la carpeta a tu vault deseado
mv Obsidian-Template "Mi-Vault-Personal"
```

### 2. Configuración

1. **Abre Obsidian** y selecciona "Abrir carpeta como vault"
2. **Selecciona la carpeta** del template descargado
3. **Confirma la instalación** de plugins de la comunidad cuando aparezca el mensaje
4. **¡Listo!** Tu vault está configurado y funcionando

### 3. Primer uso

- **Captura rápida**: Usa `00 Inbox` para ideas y notas rápidas
- **Procesamiento**: Mueve notas procesadas a `01 Permanent`  
- **Organización**: Usa `Resources` para materiales de apoyo
- **Proyectos**: Gestiona tus proyectos activos en `003 Projects`

## 🎯 Metodologías Implementadas

### 🧠 Zettelkasten

- **Notas atómicas** en `01 Permanent`
- **Enlaces bidireccionales** automáticos  
- **Sistema de numeración** para orden cronológico

### 📊 PARA Method

- **Projects** (003 Projects) - Proyectos con fecha límite
- **Areas** - Áreas de responsabilidad distribuidas
- **Resources** (000 Core/Resources) - Materiales de referencia  
- **Archive** (03 Archive) - Material inactivo

### ⚡ Getting Things Done (GTD)

- **Inbox** (00 Inbox) - Captura rápida sin fricción
- **Procesamiento** regular hacia carpetas apropiadas
- **Sistema de contextos** via tags

## 🛠️ Personalización

### Cambiar Iconos

Los stickers se pueden modificar editando el frontmatter:

```yaml
---
sticker: lucide//nuevo-icono
---
```

### Añadir Carpetas

Sigue la convención numérica:

- `004 Nueva-Categoria/`
- Añade archivo principal con sticker correspondiente

### Configurar Plugins

Cada plugin incluye configuración optimizada, pero puedes:

- Ajustar atajos de teclado en `Settings > Hotkeys`
- Modificar estilos en `Style Settings`
- Personalizar búsquedas en `Omnisearch`
