# Base cientifica

Este vault no intenta prometer aprendizaje automatico. Esta disenado para facilitar las practicas con mejor respaldo:

## Practicas principales

- Recuperacion activa: recordar sin mirar, responder preguntas y resolver problemas.
- Repeticion espaciada: volver a lo dificil en dias separados.
- Intercalado: mezclar tipos de problemas para evitar aprender solo el patron inmediato.
- Elaboracion: explicar con tus palabras, ejemplos y contraejemplos.
- Autoexplicacion: decir por que una respuesta funciona y donde podria fallar.

## Como se traduce al vault

| Practica | Donde ocurre |
|---|---|
| Captura rapida | `010 Inbox` |
| Recuperacion activa | `040 Knowledge/Flashcards`, `040 Knowledge/Problems`, `Study Session` |
| Repeticion espaciada | `050 Review/Review Queue` |
| Intercalado | `040 Knowledge/Problems`, `Study Plan` |
| Elaboracion | `040 Knowledge/Concepts` |
| Sintesis | `040 Knowledge/Maps` |
| Mantenimiento | `050 Review/Weekly Reviews` |

## Criterio

Una nota de estudio no esta completa cuando se ve bonita. Esta completa cuando puede ayudarte a recordar, aplicar o explicar algo sin mirar.
