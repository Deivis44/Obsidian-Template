# Principios del sistema

## 1. Captura rapido, procesa despues

La captura debe ser inmediata. La organizacion ocurre en revisiones, no en mitad de una clase, lectura o reunion.

## 2. Estudiar no es subrayar

El aprendizaje fuerte ocurre cuando intentas recordar, explicar y resolver sin mirar. Por eso las notas deben producir preguntas, problemas, mapas y flashcards.

## 3. Separar responsabilidades de conocimiento

`020 Areas` responde "que debo mantener". `040 Knowledge` responde "que entiendo y puedo reutilizar".

## 4. Un proyecto termina

Si no puede finalizar, no es proyecto: es area.

## 5. Enlaces con intencion

Enlaza cuando ayude a navegar una relacion real: requisito, causa, ejemplo, contradiccion, fuente o aplicacion.

## 6. Menos etiquetas, mas estructura

Usa pocas etiquetas de estado:

- `#status/seed`
- `#status/growing`
- `#status/evergreen`
- `#review`
- `#exam`

## 7. Archivar no es borrar

El archivo conserva contexto sin contaminar lo activo.
