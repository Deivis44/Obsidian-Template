# Quickstart del sistema

Este sistema prioriza baja friccion y orden suficiente. No intenta clasificar todo perfecto desde el inicio; primero captura, luego procesa, despues conecta.

## Haz esto y ya

Captura todo en `010 Inbox`. Al revisar, mueve cada nota a `020 Areas` si es una responsabilidad, a `030 Projects` si tiene cierre, a `040 Knowledge` si es conocimiento, a `050 Review` si es seguimiento, o a `090 Archive` si ya no esta activo. Para estudiar, convierte apuntes en preguntas, problemas y repasos con fecha.

## Donde va cada cosa

| Si tienes... | Guardalo en... |
|---|---|
| Una idea rapida, link, pendiente o apunte suelto | `010 Inbox` |
| Una responsabilidad sin fecha final clara | `020 Areas` |
| Un objetivo con resultado final | `030 Projects` |
| Una idea, concepto, fuente, problema o mapa de conocimiento | `040 Knowledge` |
| Revisiones, planes de estudio y agenda de aprendizaje | `050 Review` |
| Material cerrado o inactivo | `090 Archive` |

## Arbol de decision

Cuando no sepas donde poner algo, decide en este orden:

1. Todavia no se que es? -> `010 Inbox`.
2. Requiere accion concreta y termina? -> `030 Projects`.
3. Debo mantenerlo en el tiempo? -> `020 Areas`.
4. Me ayuda a entender, recordar o explicar algo? -> `040 Knowledge`.
5. Es una revision, plan o seguimiento? -> `050 Review`.
6. Ya no esta activo, pero puede servir despues? -> `090 Archive`.

## Rutina diaria minima

1. Captura sin ordenar en `010 Inbox`.
2. Estudia con preguntas, no solo lectura.
3. Cierra el dia moviendo lo obvio a su lugar.

## Rutina semanal minima

1. Vaciar Inbox.
2. Revisar proyectos activos.
3. Actualizar areas importantes.
4. Crear o ajustar plan de estudio.
5. Archivar lo que ya no esta activo.

## Criterio de calidad

Una buena nota tiene titulo claro, contexto suficiente, enlaces utiles y una pregunta que te obligue a recordar o aplicar la idea.

## Reglas anti-friccion

- Si dudas mas de 20 segundos, mandalo a `010 Inbox`.
- No crees carpetas nuevas por impulso; primero usa una nota mapa en `040 Knowledge/Maps`.
- No resumas por resumir: convierte lo importante en preguntas, problemas o conceptos.
- Un proyecto activo siempre debe tener una siguiente accion pequena.
- El sistema se mejora en la revision semanal, no durante cada captura.
